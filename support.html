Getting started (iOS)

  • Add the keyboard: Settings → General → Keyboard → Keyboards → Add New Keyboard → choose Clipo.
  • Use Clipo while typing: Switch to the Clipo keyboard where you want clipboard capture and quick access to clips.
  • Full Access: If Clipo asks you to enable Full Access for the keyboard, that allows the keyboard and the main app to work together for features such as syncing clips. Clipo does not sell your data or run ads.

Clipboard and data

  • Where data lives: History and clips are stored on your device only. There is no account or cloud sync in Clipo.
  • Removing data: Deleting the app or clearing app data removes local history. Export or copy anything important before uninstalling.
  • App lock: Optional Face ID or Touch ID protects opening the main app; use device settings inside Clipo if available.

Troubleshooting

  • Keyboard does not appear: Confirm Clipo is added under Keyboards and that you selected it from the globe / keyboard switcher.
  • Clips do not update: Ensure you are using the Clipo keyboard when copying or pasting, as capture is tied to keyboard use.
  • Missing Full Access: Settings → General → Keyboard → Keyboards → Clipo → turn on Allow Full Access if the app directs you to.
